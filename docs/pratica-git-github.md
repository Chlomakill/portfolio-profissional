# Prática de Git e GitHub

Este documento registra a aplicação prática dos conceitos estudados na trilha GitHub Foundations.

## Objetivo

Demonstrar o uso de branches, commits e Pull Requests em um repositório de portfólio.

## Fluxo utilizado

1. A branch principal do projeto é `main`.
2. Foi criada a branch `melhorias-portfolio` a partir da `main` para trabalhar separadamente.
3. Esta documentação foi adicionada na branch de melhorias em um commit próprio.
4. A branch será comparada com a `main` por meio de um Pull Request.
5. Após a revisão, as alterações poderão ser integradas à branch principal por merge.

## Conceitos

- **Branch:** linha de desenvolvimento separada, que permite trabalhar sem alterar diretamente a branch principal.
- **Commit:** registro de uma alteração no histórico do projeto, acompanhado de uma mensagem que explica o que foi feito.
- **Pull Request:** proposta para integrar as alterações de uma branch em outra, permitindo revisar as diferenças.
- **Merge:** integração das alterações aprovadas à branch de destino.

## Evidência

O histórico desta branch e o Pull Request associado demonstram a prática desses recursos no GitHub.
