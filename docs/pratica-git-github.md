# Prática de Git e GitHub

Neste arquivo, deixei registrado como usei alguns recursos do Git e do GitHub durante a atividade de GitHub Foundations.

## O que foi feito

A ideia foi praticar o uso de branches, commits e Pull Requests em um repositório que já faz parte do meu portfólio.

Primeiro, usei a branch principal, chamada `main`, como base. Depois, criei uma branch chamada `melhorias-portfolio` para fazer as alterações separadamente, sem mexer direto na versão principal.

Nessa branch, adicionei este arquivo explicando o processo. As mudanças ficaram registradas em commits com mensagens para identificar o que foi feito. Em seguida, abri um Pull Request para comparar a branch de melhorias com a `main`. Depois de conferir as alterações, fiz o merge e integrei o conteúdo à branch principal.

## Alguns conceitos que pratiquei

- **Branch:** é uma ramificação do projeto. Ela permite fazer alterações separadamente, sem afetar diretamente a `main`.
- **Commit:** é o registro de uma alteração feita no projeto. A mensagem ajuda a entender o que mudou.
- **Pull Request:** é usado para apresentar as mudanças de uma branch e propor que elas sejam adicionadas a outra.
- **Merge:** é a etapa em que as alterações de uma branch são integradas à branch de destino.

## O que aprendi

Com essa atividade, consegui praticar o fluxo básico de trabalho com GitHub. Também entendi melhor como as branches ajudam a organizar as alterações e como o Pull Request permite revisar o que foi feito antes de juntar tudo na `main`.
